# Phase 1 — Core CRM & Pipeline (Days 1–10)

## Purpose
Stand up the core GoHighLevel (GHL) CRM, referral‑to‑resident pipeline, intake forms, bed management dashboard, and calendar scheduling required to operate DG Res Care. This phase establishes the system foundation for automation and reporting.

## Scope (Phase 1)
1. GHL account setup + user permissions
2. Contact import + segmentation tags
3. Custom fields creation
4. Referral‑to‑resident pipeline (8 stages) + notifications
5. Intake forms (Initial Inquiry + Screening)
6. Bed Management Dashboard (17 beds)
7. Calendar integration (owner availability + reminders)
8. Phase 1 testing + sign‑off

## Dependencies / Inputs Needed
- GHL account access (admin)
- Owner + VA users list and permissions
- Existing contacts CSV
- Property/bed layout (17 beds across 2 properties)
- Website access for form embed
- Owner calendar (Google/Outlook)

## Deliverables
- Configured GHL account and user roles
- Contact tags and custom fields created
- 8‑stage referral pipeline with notifications
- Two embedded intake forms
- Bed Management Dashboard with summary metrics
- Calendar appointment types and reminder automations
- Phase 1 test report + owner sign‑off

## Acceptance Criteria
- Contacts created from forms and routed to **New Inquiry** stage
- Stage change notifications fire correctly (text/email/in‑app)
- Custom fields visible and editable on contacts
- Bed dashboard shows all 17 beds and status colors
- Calendar bookings appear on owner calendar with reminders
- End‑to‑end pipeline test passes

## Risks
- Delays in access or data provisioning
- Bed layout uncertainty
- Website embed delays

## Phase 1 Sign‑Off
Owner confirms:
- CRM works end‑to‑end
- Forms embedded and functioning
- Bed dashboard accurate
- Calendar integration stable
- Ready to proceed to Phase 2
